# 插件与节点图

OpenUUYC 提供 DLL 插件宿主和节点图编辑器。一个插件可以提供多个节点，节点之间通过明确的数据类型连接。当前执行与渲染后端为 Windows。

本仓库公开插件 SDK 和一个可构建的示例：**画面滤镜**，包含色彩调整、锐化和像素化。客户端不内置这些滤镜算法。

## 节点图操作

在“插件管理 → 节点图”中新建图，从节点库按住拖入节点，再拖动同类型端口建立连接。节点参数直接在节点内编辑。

- **保存**只保存草稿；**应用**保存并发布到使用该图的观看窗口。
- 播放器控制栏的插件菜单用于选择、启用节点图。
- 新图准备失败时，原图继续运行，界面显示失败原因。
- 中键拖动画布，滚轮缩放；双击连线添加中继点，右键删除或断开。
- 撤销、重做、适应画布和整理节点位于工具栏。

## 插件文件与参数

每个插件使用独立目录。宿主优先读取程序旁的 `plugins/`；该目录不存在时，读取 `%LOCALAPPDATA%/OpenUUYC/plugins/`。

固定清单编译进 DLL，安装时不需要旁置 JSON。`manifest.json` 是源码中的构建输入。节点参数保存在节点图中；没有节点的服务模块，其用户设置保存在 `%LOCALAPPDATA%/OpenUUYC/plugin-settings/`。

节点依赖按实际使用加载；只安装或浏览插件不会初始化其推理服务。独立进程用于隔离插件故障，不是安全沙箱。
