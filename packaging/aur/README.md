# AUR packages

Two packages for Arch and Omarchy users:

| Package | Source | Build time |
|---|---|---|
| `openuuyc-bin` | GitHub Release binary | seconds |
| `openuuyc-git` | `omarchy` branch | 20–40 min |

Both install the same files: `/usr/bin/OpenUUYC`, the launch wrapper, the
desktop entry, the icon, the systemd user unit, and the uinput udev rule.

## Publishing to the AUR

The AUR is a separate git remote per package, so this repository only carries
the source of truth. To publish a version:

```bash
# 1. Tag the release in this repository first (the PKGBUILD fetches the tag):
git tag v1.0.0-omarchy.1
git push origin omarchy --tags

# 2. openuuyc-bin
git clone ssh://aur@aur.archlinux.org/openuuyc-bin.git /tmp/aur-openuuyc-bin
cp packaging/aur/openuuyc-bin/PKGBUILD packaging/aur/openuuyc-bin/openuuyc-bin.install \
   /tmp/aur-openuuyc-bin/
cd /tmp/aur-openuuyc-bin
# Fill in the real checksums: makepkg prints the array to paste back.
updpkgsums
makepkg --printsrcinfo > .SRCINFO
git add -A && git commit -m "openuuyc-bin 1.0.0.omarchy.1" && git push

# 3. openuuyc-git (only when the recipe changes; pkgver tracks the branch)
git clone ssh://aur@aur.archlinux.org/openuuyc-git.git /tmp/aur-openuuyc-git
cp packaging/aur/openuuyc-git/PKGBUILD packaging/aur/openuuyc-git/openuuyc-git.install \
   /tmp/aur-openuuyc-git/
cd /tmp/aur-openuuyc-git
makepkg --printsrcinfo > .SRCINFO
git add -A && git commit -m "openuuyc-git: track the omarchy branch" && git push
```

The first push to a non-existent AUR repository creates it, provided you have
an SSH key registered on your AUR account.

## Version numbers

`pkgver` cannot contain a hyphen, so the tag `v1.0.0-omarchy.1` becomes
`1.0.0.omarchy.1`. The PKGBUILD derives the tag back with
`_tag=v${pkgver/omarchy./omarchy-}`.

For `openuuyc-git` the version is generated by `pkgver()` from `Cargo.toml`
plus `git describe`, so no manual edit is needed after the first commit.

## Checksums

`openuuyc-bin` ships `sha256sums=('SKIP' ...)` in this repository so the file
stays readable, but the AUR copy **must** have real hashes. Run `updpkgsums`
before the first push and on every version bump; AUR reviewers reject `SKIP`
for release artifacts.

## Local testing

```bash
cd packaging/aur/openuuyc-bin
makepkg -si
# or, without installing:
makepkg --nobuild --verifysource   # checks the URLs resolve
namcap PKGBUILD
```
