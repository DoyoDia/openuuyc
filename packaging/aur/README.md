# AUR packages

Two packages for Arch and Omarchy users:

| Package | Source | Build time |
|---|---|---|
| `openuuyc-bin` | Release archive of a `v*-linux.*` tag on DoyoDia/openuuyc | seconds |
| `openuuyc-git` | `linux-port` branch of DoyoDia/openuuyc | 20–40 min |

Both install the same files: `/usr/bin/OpenUUYC`, the desktop entry, the
icon, the uinput udev rule and the license texts. Login startup is the
settings page's 「开机自启」 switch (an XDG autostart entry), so the packages
ship no systemd unit.

## Releases

A release is a tag `v<Cargo version>-linux.<n>` on DoyoDia/openuuyc, for
example `v1.0.1-linux.1`. Pushing it runs two workflows that attach to the
same GitHub release:

- `linux-deb.yml`: the Debian/Ubuntu `.deb`;
- `linux-release.yml`: the Arch-built binary and
  `OpenUUYC-<version>-x86_64-linux.tar.zst`, which has the repository's
  layout (binary, `packaging/`, `assets/icon-256.png`, licenses and
  `install-omarchy.sh`). `openuuyc-bin` installs from this archive.

## Publishing to the AUR

The AUR is a separate git remote per package, so this repository only carries
the source of truth. After the release above exists:

```bash
# openuuyc-bin: set pkgver to the tag (v1.0.1-linux.1 -> 1.0.1.linux.1)
git clone ssh://aur@aur.archlinux.org/openuuyc-bin.git /tmp/aur-openuuyc-bin
cp packaging/aur/openuuyc-bin/PKGBUILD packaging/aur/openuuyc-bin/openuuyc-bin.install \
   /tmp/aur-openuuyc-bin/
cd /tmp/aur-openuuyc-bin
updpkgsums                      # replace SKIP with the archive's real checksum
makepkg --printsrcinfo > .SRCINFO
git add -A && git commit -m "openuuyc-bin 1.0.1.linux.1" && git push

# openuuyc-git (only when the recipe changes; pkgver tracks the branch)
git clone ssh://aur@aur.archlinux.org/openuuyc-git.git /tmp/aur-openuuyc-git
cp packaging/aur/openuuyc-git/PKGBUILD packaging/aur/openuuyc-git/openuuyc-git.install \
   /tmp/aur-openuuyc-git/
cd /tmp/aur-openuuyc-git
makepkg --printsrcinfo > .SRCINFO
git add -A && git commit -m "openuuyc-git: update the recipe" && git push
```

The first push to a non-existent AUR repository creates it, provided you have
an SSH key registered on your AUR account.

## Version numbers

`pkgver` cannot contain a hyphen, so the tag `v1.0.1-linux.1` becomes
`1.0.1.linux.1`, and the PKGBUILD maps it back with
`_tag=v${pkgver/.linux./-linux.}`.

For `openuuyc-git` the version is generated by `pkgver()` from `Cargo.toml`
plus the commit count and hash, so no manual edit is needed.

## Checksums

`openuuyc-bin` ships `sha256sums=('SKIP')` in this repository, but the AUR
copy **must** have the real hash. Run `updpkgsums` on every version bump;
AUR reviewers reject `SKIP` for release artifacts.

## Local testing

```bash
cd packaging/aur/openuuyc-bin
makepkg --nobuild --verifysource   # checks the archive URL resolves
makepkg -si
namcap PKGBUILD
```
